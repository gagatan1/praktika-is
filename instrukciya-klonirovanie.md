# Инструкция: как создать локальную копию удалённого репозитория GitHub

Источник: официальная документация GitHub — «Клонирование репозитория»
https://docs.github.com/ru/repositories/creating-and-managing-repositories/cloning-a-repository

Локальный репозиторий — это полная копия удалённого репозитория на компьютере: файлы, история коммитов и связь с GitHub. Создаётся она командой `git clone`.

Ниже способ через SSH. Он подходит, если ключ уже создан и добавлен в GitHub (Settings → SSH and GPG keys).

## 1. Открыть репозиторий и скопировать SSH-адрес

1. На GitHub открыть главную страницу нужного репозитория.
2. Над списком файлов нажать зелёную кнопку **Code**.
3. Выбрать вкладку **SSH**.
4. Скопировать адрес. Он выглядит так:

```text
git@github.com:USERNAME/REPOSITORY.git
```

`USERNAME` — имя аккаунта, `REPOSITORY` — имя репозитория.

## 2. Клонировать репозиторий

1. Открыть Git Bash (Windows: правый клик в нужной папке → Git Bash Here) или терминал.
2. Перейти в папку, где должна появиться копия:

```bash
cd /путь/к/папке
```

3. Выполнить клонирование, подставив свой адрес:

```bash
git clone git@github.com:USERNAME/REPOSITORY.git
```

4. Git создаст папку с именем репозитория и скачает в неё все файлы и историю.
5. Перейти в эту папку:

```bash
cd REPOSITORY
```

Проверка связи с удалённым репозиторием:

```bash
git remote -v
```

В выводе должна быть строка `origin` с тем же SSH-адресом. `origin` — это имя удалённого репозитория, которое Git даёт ему при клонировании.

## 3. Как отправить изменения обратно на GitHub

После правок в локальной копии их нужно зафиксировать и отправить.

```bash
git add .
git commit -m "Добавлена инструкция по клонированию репозитория"
git push
```

- `git add .` — подготовить изменённые файлы;
- `git commit` — сохранить их в локальной истории;
- `git push` — отправить коммит в удалённый репозиторий на GitHub.

При первом `git push` Git может спросить, доверять ли ключу GitHub (`Are you sure you want to continue connecting?`). Нужно ответить `yes`. Если при создании ключа задавался passphrase, его нужно ввести.

## Замечание про пустой репозиторий

Если репозиторий только что создан и в нём ещё нет коммитов, GitHub на странице репозитория сам показывает команды. Можно клонировать пустой репозиторий той же командой `git clone`, а затем добавить файлы, сделать commit и push, как в пункте 3.
